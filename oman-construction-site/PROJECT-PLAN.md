# Oman Construction Website Project Plan

## Plan

- Position the website as a lead-generation and credibility platform for a construction company in Oman.
- Build a polished multi-page site with clear service architecture, project proof, trust signals, and strong contact paths.
- Keep risky actions approval-gated. Production deployment, domain changes, and third-party integrations should be confirmed before execution.

## Build

- Create a Next.js + Tailwind project scaffold.
- Build reusable sections and a shared content model.
- Implement key pages:
  - Home
  - About Us
  - Services
  - Projects
  - Sectors
  - Quality & Safety
  - Careers
  - Contact
  - Request a Quote

## Output

- Deliver project files ready for dependency install and local run.
- Provide deployment options for Vercel and VPS-based hosting.
- Provide content placeholders that can be replaced with real company details.

## Improve

- Add bilingual English/Arabic support.
- Replace placeholder brand and portfolio copy with real company content.
- Add CMS integration, analytics, SEO pages, and project filtering.
- Add form backend or CRM connection after approval.

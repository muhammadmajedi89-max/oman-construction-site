# Oman Construction Website

Next.js + Tailwind starter for a construction company website focused on the Oman market.

## Included

- Multi-page marketing site structure
- Home, About, Services, Projects, Sectors, Quality & Safety, Careers, Contact, Request a Quote
- Reusable content-driven page sections
- Project plan and deployment guidance

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open `http://localhost:3000`

## Build for production

```bash
npm run build
npm run start
```

## GitHub + Vercel

1. Create a new GitHub repository.
2. Push this project to the default branch.
3. Import the repository into Vercel.
4. Keep the default Next.js framework detection.
5. Add any required environment variables before enabling live form handling.
6. Connect the final domain only after approval.
